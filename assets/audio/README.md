# Audio Assets (`/assets/audio` & `/public/audio`)

`game/audio.ts` synthesizes all sound effects (wooden piece clicks, selection chimes, water ripples, leap whooshes, capture impacts, Vietnamese pentatonic fanfare, background melody, and forest bird ambience) directly via the Web Audio API without requiring external copyrighted audio files.

Optional custom `.mp3` / `.ogg` files can be placed in `/public/audio/`:
- `click.mp3`
- `select.mp3`
- `move.mp3`
- `swim.mp3`
- `capture.mp3`
- `victory.mp3`
- `bgm.mp3`
- `ambient.mp3`
